SYSTEM CONFIGURATION

คู่มือการตั้งค่าเครื่องก่อนใช้งาน (Setup Guide)

ตั้งค่าระบบเสียงเข้า Discord แบบ 0ms Studio Master

⚡ ตัวช่วยเปิดหน้าตั้งค่า 1 คลิก (Setup Helper)

กดดาวน์โหลดไฟล์ .bat แล้วดับเบิ้ลคลิก ตัวสคริปต์จะเปิดหน้าต่างตั้งค่าให้อัตโนมัติทันที

📥 ดาวน์โหลดไฟล์ .BAT
1

ติดตั้งไดรเวอร์สายสัญญาณเสมือน (VB-Audio Virtual Cable)

จำเป็นต้องมีเพื่อให้บราวเซอร์สามารถส่งเสียงดนตรีและเสียงก้อง Reverb เข้าไปใน Discord ได้

🔹 ดาวน์โหลดและแตกไฟล์: ดาวน์โหลด VB-Cable Driver (ZIP)
🔹 คลิกขวาที่ VBCABLE_Setup_x64.exe ➔ เลือก Run as Administrator แล้วกด Install Driver
🔹 รีสตาร์ตเครื่องคอม 1 ครั้ง หลังจากติดตั้งเสร็จ
2

ตั้งค่า Windows Sound (ส่งเสียงไมค์เข้าสาย Cable)

ขั้นตอนนี้ทำให้เสียงร้องสดของคุณส่งตรงเข้า Discord แบบ 0ms (Zero-Latency)

🔹 เปิดหน้าต่าง Sound Control Panel (หรือดับเบิ้ลคลิกไฟล์ Setup-Windows-Audio.bat)
🔹 ไปที่แท็บ Recording (การบันทึก) ➔ ดับเบิ้ลคลิกที่ ไมโครโฟนของคุณ (เช่น Maono Fairy)
🔹 ไปที่แท็บ Listen (การฟัง) ➔ ติ๊กถูกที่ ☑️ Listen to this device (ฟังอุปกรณ์นี้)
🔹 ช่อง Playback through this device ➔ เลือกเป็น CABLE Input (VB-Audio Virtual Cable) แล้วกด OK
3

ตั้งค่าไมค์ใน Discord (เลือกช่องสัญญาณ Cable)

เพื่อให้เพื่อนในห้องได้ยินทั้งเสียงร้องสด, ดนตรี และ Reverb พร้อมกัน

🔹 ใน Discord ไปที่ User Settings (ฟันเฟือง) ➔ Voice & Video
🔹 Input Device (อุปกรณ์เสียงเข้า) ➔ เลือกเป็น CABLE Output (VB-Audio Virtual Cable)
🔹 Output Device (อุปกรณ์เสียงออก) ➔ เลือกเป็น หูฟังของคุณตามปกติ
🔹 เลื่อนลงไปที่ Noise Suppression ➔ ปรับเป็น None (ปิด) (ห้ามเปิด Krisp เพื่อป้องกันเสียงเพลงโดนตัด)
4

เลือกช่องสัญญาณบนหน้าเว็บ Karaoke Cloud Studio

🔹 ช่อง 🎧 1. หูฟังของเรา ➔ เลือกหูฟังที่คุณใช้ฟังเพลง
🔹 ช่อง 🎙️ 2. ส่งเข้าเกม/Discord ➔ เลือก CABLE Input (VB-Audio Virtual Cable)
🔹 กดปุ่ม ⚡ START ENGINE ด้านบนขวา แล้วเริ่มค้นหาเพลงร้องได้เลย!
