# Nocturne Studio (Karaoke Sync Player)

Precision real-time vocal audio studio and YouTube karaoke player with hardware dual-routing for Discord & FiveM.

## Product Truth

### Primary Users & Jobs
- **Users**: Discord voice chat singers, FiveM GTA V roleplayers, streamers, and gamers.
- **Jobs to be done**:
  - Play YouTube backing track karaoke with real-time key shifting (±6 semitones).
  - Real-time vocal auto-tune (YIN pitch detection + musical scale quantization).
  - Dual audio output routing: Direct low-latency monitoring to user headphones + mixed audio routed into VB-CABLE for Discord/FiveM.
  - Zero-latency hardware sync calibration (120ms default preset) to ensure vocals and music sync perfectly in Discord.
  - Record test & playback verification to hear exactly what is sent to Discord before live performance.

## Platform & Technical Architecture
- **Platform**: Web (HTML5, Vanilla JS, Web Audio API, AudioWorklet).
- **Audio DSP Engine**: 100% Client-side Web Audio API for 0ms processing.
- **Backend / Deployment**: Node.js / Express local server, Cloudflare Tunnel, Vercel Serverless ready.
